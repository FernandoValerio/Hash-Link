**# Manual do Usuário**



**## Iniciando**



**Abra o aplicativo \*\*Hash link\*\*.**



**Não é necessário utilizar terminal.**



**---**



**## Nova aquisição**



**1. Acesse "Nova aquisição".**

**2. Informe a URL.**

**3. Clique em "Analisar".**

**4. Aguarde a identificação do recurso.**



**---**



**## Selecionando arquivos**



**Após a análise, os arquivos encontrados serão apresentados.**



**Selecione os arquivos desejados.**



**É possível utilizar:**



**\* Selecionar todos;**

**\* Desmarcar todos;**

**\* pesquisa;**

**\* filtros.**



**---**



**## Escolhendo algoritmos**



**Selecione os algoritmos desejados.**



**Recomenda-se manter:**



**```text**

**SHA-256**

**```**



**selecionado.**



**---**



**## Iniciando**



**Clique em:**



**```text**

**Iniciar aquisição**

**```**



**O sistema realizará o download e calculará os hashes.**



**---**



**## Conclusão**



**Após a conclusão, os resultados estarão disponíveis na tela.**



**O usuário poderá:**



**\* visualizar;**

**\* copiar;**

**\* exportar;**

**\* abrir a pasta;**

**\* consultar posteriormente pelo histórico.**



**---**



**## Histórico**



**A tela Histórico permite localizar aquisições anteriores.**



**Cada aquisição possui um identificador único.**



**Nenhuma aquisição concluída deve ser sobrescrita automaticamente.**
