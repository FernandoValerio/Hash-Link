# 🔗 Hash Link v0.1.0
# Release Notes

## 🎉 Primeira Versão Funcional

A versão 0.1.0 marca a primeira entrega funcional do projeto Hash Link.

## ✨ Principais Funcionalidades

- Interface gráfica PySide6
- Descoberta de arquivos por URL
- Integração inicial com Google Drive
- Integração inicial com OneDrive/SharePoint
- Download de arquivos selecionados
- Cálculo de hash SHA-256
- Exibição de resultados

## 📦 Tecnologias

- Python 3.11
- PySide6
- Playwright
- Requests
- BeautifulSoup4
- OpenPyXL
- ReportLab

## 🚧 Limitações Conhecidas

- Manifesto em evolução
- Exportadores ainda não integrados ao fluxo principal
- Suporte OneDrive em evolução
- Histórico ainda não persistido
